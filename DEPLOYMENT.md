# Laravel API Deployment Guide

**API URL:** `https://api.scrapifyauctions.com`  
**Server:** Hostinger Shared Hosting  
**Deployment Method:** GitHub Actions (Automatic)

---

## Overview

This Laravel API automatically deploys to Hostinger whenever code is pushed to the `main` branch. No manual steps needed!

### What Happens Automatically:

1. ✅ Code cloned from GitHub
2. ✅ PHP dependencies installed (Composer)
3. ✅ Environment variables loaded from GitHub Secrets
4. ✅ Database migrations run
5. ✅ Application caches cleared
6. ✅ Files deployed to production
7. ✅ Permissions set correctly

---

## Deployment Workflow

**File:** `.github/workflows/deploy-api.yml`

**Triggers:**
- Every push to `main` branch
- Manual trigger via GitHub Actions

**Steps:**
1. Checkout code
2. SSH to Hostinger server
3. Clone/update repository
4. Install dependencies
5. Setup `.env` file
6. Generate app key
7. Run migrations
8. Clear caches
9. Deploy to public_html

## GitHub Secrets (Required)

All these must be set in your GitHub repo settings:

| Secret | Value | Example |

| `HOSTINGER_HOST` | Server IP | `147.93.101.65` |
| `HOSTINGER_PORT` | SSH Port | `65002` |
| `HOSTINGER_USER` | SSH Username | `u551475123` |

| `DB_PORT` | Database Port | `3306` |

| `DB_PASSWORD` | Database Password | (Your secure password) |

## Troubleshooting

### Deployment Failed

Check GitHub Actions logs:
1. Go to Actions tab
2. Click the failed workflow
3. Expand the "Deploy to Hostinger" step
4. Read error messages

**Common Issues:**

| Issue | Solution |
|-------|----------|
| SSH Key Error | Verify SSH key secret is the PRIVATE key (not public) |
| Database Error | Check DB_HOST, DB_USERNAME, DB_PASSWORD secrets |
| Permission Error | SSH key permissions must be 600 on local machine |
| Composer Error | Ensure composer.json exists and is valid |

### Manual SSH to Server

```bash
ssh -i ~/.ssh/scrapify_deploy -p 65002 u551475123@147.93.101.65

# Check deployment location
cd /home/u551475123/domains/api.scrapifyauctions.com/public_html

# View logs
tail -f storage/logs/laravel.log

# Check permissions
ls -la storage/
```

## Environment Variables

Copy `.env.example` to `.env` on the server (GitHub Actions does this automatically).

Key variables:

```
APP_URL=https://api.scrapifyauctions.com
DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
JWT_SECRET=(auto-generated by artisan key:generate)
```

## Database Migrations

Migrations run automatically on every deployment:

```bash
php artisan migrate --force
```

**Important:** 
- Add new migrations to `database/migrations/`
- Commit to Git
- Push to main → Automatic deployment → Migrations run

## Rollback

If deployment fails and you need to rollback:

```bash
# SSH to server
ssh -i ~/.ssh/scrapify_deploy -p 65002 u551475123@147.93.101.65

# Check git log
cd /home/u551475123/domains/api.scrapifyauctions.com/scrapify-auction-api
git log --oneline

# Checkout previous commit
git checkout <commit-hash>

# Reinstall and migrate
composer install
php artisan migrate
```

## Security

**Never commit:**
- `.env` file
- Passwords or API keys
- Private SSH keys

**Use GitHub Secrets instead!**

All sensitive data should be in GitHub Secrets, not hardcoded.
